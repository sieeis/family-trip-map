# 지도 UI 상태와 모바일 규칙

이 문서는 이번 사용자가 선택한 UX다. 새로운 프로젝트의 요구가 다르면 조정한다.

## 선택과 카메라

| 이벤트 | 동작 |
|---|---|
| 첫 로딩/그룹명 클릭 | 그룹 장소 bounds에 맞춤, 선택/필터 초기화 |
| 목록 항목 첫 클릭 | 해당 핀 중앙 이동, 선택 강조 |
| 같은 목록 항목 재클릭 | 선택 취소, 그룹 전체 보기 |
| 지도 핀 클릭 | 현재 zoom 유지, 중앙 이동과 강조만 |
| 상세보기 버튼 클릭 | 팝업 열기 |
| 현재 위치 버튼 | 최신 위치로 setCenter만; zoom 변경 금지 |
| 위치 watch 갱신 | 파란 위치 점만 갱신; 카메라 자동 추적 금지 |

그룹의 활성 상태와 장소 선택 상태를 혼동하지 않는다. '전체'는 이 사례에서 현재 그룹 전체다. fitBounds에는 버튼 영역과 라벨 여백을 고려한다. 좌표 0은 유효할 수 있으므로 truthiness가 아니라 finite/range로 검사한다.

## 카테고리·아이콘·겹침

- 기본 카테고리 팔레트: 맛집 빨강 #F00000, 관광지 파랑 #004CFF, 숙소 보라 #8000C8, 체험 노랑 #FFE000, 카페 청록 #00D8E8, 쇼핑 초록 #009900, 기타 #343A40. 사용자 지정 색은 보존한다.
- 색만으로 의미를 전달하지 않는다. 핀 내부의 밝은 원 위에 기존 카테고리 SVG 아이콘을 축소 배치한다. 이 사례는 38×48 핀 안 18×18 아이콘이다. 테마에 따른 SVG 변형을 공유하고 새로 이미지를 내려받지 않는다.
- 선택된 핀은 굵은 테두리/halo와 높은 zIndex로 강조한다. 선택 해제 시 원래 스타일로 복구한다.
- 이름은 Unicode 문자 기준 앞 6개와 필요 시 …; 상세 팝업은 전체 이름. 결합 문자/복합 이모지를 많이 쓰는 제품은 Intl.Segmenter로 grapheme 단위를 사용한다.
- 평상시 이름표·버튼의 실제 CSS 크기와 핀 bounding rect를 비교한다. 서로 겹치거나 지도 컨트롤을 가리는 카드는 숨긴다. zoom/idle/resize에 재계산하고 requestAnimationFrame으로 같은 프레임의 갱신을 합친다.
- **선택 핀의 카드는 겹침 숨김 예외**다. 가장 앞에 표시하고 뷰포트 안으로 clamp한다. 선택 카드를 가리는 다른 카드는 숨긴다. 선택 핀의 상세 버튼까지 사라지면 사용자가 상세를 열 수 없다.
- 카드 크기를 바꾸면 충돌 계산 크기도 함께 수정한다. SDK 내부 DOM 전체를 재작성하지 말고 앱 소유 레이어만 관리한다.

## 모바일 레이아웃

지도는 항상 보이게 두고 그룹/장소 목록을 제목 위주로 접는다. 지도 오른쪽에는 ALL/①/내 위치 44px 버튼을 세로 배치한다. 왼쪽 카테고리 필터는 현재 그룹에 존재하는 종류만, 모바일은 글자 없이 세로 아이콘; aria-label은 유지한다. 짧은 화면에서는 지도 컨트롤이 잘리지 않도록 wrap/여백을 확인한다.

상단 제목·정렬·접기 버튼을 space-between으로만 배치하면 정렬 버튼이 가운데로 밀린다. 정렬 버튼에 margin-left:auto 또는 제목 영역 flex:1을 사용해 오른쪽 끝을 맞춘다. 접힘/펼침·편집 모드·긴 제목·320/390px·가로화면에서 확인한다.

## 현재 위치

HTTPS와 브라우저 위치 권한이 필요하다. 기기의 위치는 공유 저장소에 저장하지 않고 해당 사용자의 화면에서만 사용한다. watchPosition을 중복 등록하지 말고 pagehide 등에서 정리하고 복귀를 처리한다. 권한 거부/timeout/지원 안 함 메시지를 구별한다. 성공 전 버튼 busy를 정리한다. 내 위치 이동 후 resize나 데이터 sync가 이전 장소 zoom을 복원하지 않는지 테스트한다.

## API 호출과 길찾기

테마·목록 정렬·핀 색·상세 열기는 로컬 데이터로 처리한다. pan/zoom으로 SDK 타일 네트워크 요청은 발생할 수 있다. JS 메서드 호출 수와 실제 과금 건수는 같다고 단정하지 않는다.

2026-09-09 확인한 Directions 5/15는 자동차 경로·거리(m)·소요시간(ms)·경로 좌표·통행료 등을 제공했다. 도보는 이 Directions API에서 지원하지 않았다. 확인한 옵션은 빠른 길/편한 길/최적/무료/자동차전용도로 회피이며 순수 거리 최소 보장은 하지 않는다. 현재 프로젝트에는 길찾기를 구현하지 않았다. 새 작업에서는 서비스 활성화, 서버 인증키, 최신 명세를 확인한다.
