# 가족 여행지 지도

네이버지도 공유 링크로 장소를 모으는 공용 여행 지도입니다.
같은 사이트에 접속한 모두가 그룹과 장소를 조회·추가·수정·삭제합니다.

## 저장과 동기화

- `/api/trips`가 Vercel Private Blob의 `family-trip/state.json`을 읽고 씁니다.
- 서버 환경 변수 `BLOB_READ_WRITE_TOKEN`은 연결한 Blob 저장소에서 발급됩니다. 브라우저에 노출하지 않습니다.
- 데이터 파일 자체는 비공개이지만 앱의 조회·수정 API는 로그인 없이 공개됩니다. 현재 의도한 공동 편집 방식입니다.
- 열린 화면은 15초마다 갱신합니다. 편집창이 열린 동안에는 자동 갱신을 멈춥니다.
- ETag 조건부 저장으로 다른 기기의 변경을 덮어쓰지 않습니다. 충돌하면 최신 목록을 불러오고 입력창을 유지합니다.
- 저장에 실패하면 성공으로 표시하지 않습니다. 오프라인 편집은 지원하지 않습니다.
- 백업 가져오기의 ‘덮어쓰기’와 삭제는 모든 사용자에게 적용됩니다. 상단 내보내기로 JSON 백업을 받을 수 있습니다.

## 기존 기기 데이터 이전

예전 버전은 `ftm_groups`, `ftm_places`를 브라우저 localStorage에 저장했습니다.
기존 데이터가 있는 기기에서 **이 기기의 기존 데이터 공유**를 누르면 ID 기준으로 병합합니다.
이미 같은 ID가 있으면 공용 데이터를 유지하며 원래 로컬 데이터는 백업으로 남깁니다.
공유가 끝난 기기에는 이전 버튼을 다시 표시하지 않습니다.

## 개발과 배포

```text
npm ci
npm test
vercel deploy --prod
```

운영 Vercel 프로젝트에 Private Blob 저장소를 연결해야 합니다. 테스트는 운영 데이터를 변경하지 않습니다.
GitHub `main` 푸시는 연결된 Vercel 운영 배포를 실행합니다.

지도 SDK 인증에는 `ncpKeyId`를 사용합니다. 장소 가져오기는 현재 네이버 지도 웹사이트의 공개 조회 경로에 의존하며, 공식 Open API 계약이 아니므로 경로나 응답 구조가 바뀌면 `api/naver-place.js`를 갱신해야 합니다.
