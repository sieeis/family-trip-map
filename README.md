# 가족 여행지 지도

네이버지도 공유 링크로 장소를 모으는 공용 여행 지도입니다.
기본은 읽기 전용입니다. 상단 자물쇠를 열면 누구나 그룹과 장소를 추가·수정·삭제할 수 있습니다. 새로 접속하면 다시 잠깁니다.

## 저장과 동기화

- `/api/trips`가 Vercel Private Blob의 `family-trip/state.json`을 읽고 씁니다.
- 서버 환경 변수 `BLOB_READ_WRITE_TOKEN`은 연결한 Blob 저장소에서 발급됩니다. 브라우저에 노출하지 않습니다.
- 데이터 파일 자체는 비공개이지만 앱의 조회·수정 API는 로그인 없이 공개됩니다. 현재 의도한 공동 편집 방식입니다.
- 편집 잠금은 실수 방지를 위한 화면 모드이며 비밀번호 인증이 아닙니다. 저장 요청에는 `X-Trip-Edit: 1`을 포함해야 합니다.
- 열린 화면은 15초마다 갱신합니다. 편집창이 열린 동안에는 자동 갱신을 멈춥니다.
- ETag 조건부 저장으로 다른 기기의 변경을 덮어쓰지 않습니다. 충돌하면 최신 목록을 불러오고 입력창을 유지합니다.
- 저장에 실패하면 성공으로 표시하지 않습니다. 오프라인 편집은 지원하지 않습니다.
- 백업 가져오기의 ‘덮어쓰기’와 삭제는 모든 사용자에게 적용됩니다.

## 조회와 내보내기

- 목록과 상세 정보는 저장된 데이터를 사용하며 네이버 API를 호출하지 않습니다.
- 지도 SDK는 첫 화면에서 한 번 로드하며 최상위 그룹의 모든 핀을 표시합니다. 같은 데이터로 마커와 지도 범위를 다시 만들지 않습니다. 지도 이동·확대 시에는 네이버 타일 요청이 발생할 수 있습니다.
- 그룹·장소 패널의 접기 버튼으로 공간을 확보할 수 있습니다.
- **내보내기**에서 JSON, Markdown, Excel 또는 세 파일을 담은 ZIP을 선택합니다. 현재 선택한 그룹과 그 그룹의 모든 장소만 포함합니다. 화면에 표시되는 그룹 정보·장소 정보·네이버지도 URL만 내보내고 내부 ID, 좌표, 생성 시각, revision은 제외합니다.
- Excel은 여행지 시트 하나의 표로 제공하며 장소별 행에 그룹 정보를 함께 표시합니다. Markdown도 단일 표이고 JSON은 같은 열의 행 배열입니다. 장소가 없는 그룹은 그룹 정보만 한 행으로 내보냅니다. 이 보고서용 JSON은 기존 전체 데이터 백업 가져오기 형식과 다릅니다.

## 기존 기기 데이터 이전

예전 버전은 `ftm_groups`, `ftm_places`를 브라우저 localStorage에 저장했습니다.
기존 데이터가 있는 기기에서 편집 잠금을 풀고 **기존 데이터 공유**를 누르면 ID 기준으로 병합합니다.
이미 같은 ID가 있으면 공용 데이터를 유지하며 원래 로컬 데이터는 백업으로 남깁니다.
공유가 끝난 기기에는 이전 버튼을 다시 표시하지 않습니다.

## 개발과 배포

```text
npm ci
npm test
vercel deploy --prod
```

운영 Vercel 프로젝트에 Private Blob 저장소를 연결해야 합니다. 테스트는 운영 데이터를 변경하지 않습니다.
GitHub `main` 푸시는 연결된 Vercel 운영 배포를 실행합니다.

지도 SDK 인증에는 `ncpKeyId`를 사용합니다. 장소 가져오기는 현재 네이버 지도 웹사이트의 공개 조회 경로에 의존하며, 공식 Open API 계약이 아니므로 경로나 응답 구조가 바뀌면 `api/naver-place.js`를 갱신해야 합니다.

### 여러 장소 한 번에 추가
- 편집 모드에서 그룹을 선택하고 **여러 장소 추가**를 누릅니다. 네이버지도 개별 장소 공유 URL을 한 줄에 하나씩, 최대 50개 입력합니다.
- **불러오기**는 동시에 2개씩 조회합니다. 성공한 정보 확인 후 **성공 N개 추가**를 누르면 한 번의 저장 요청으로 현재 그룹에 추가합니다.
- 입력 목록 및 현재 그룹의 중복 장소는 제외합니다. 실패한 링크만 재시도할 수 있고, 창을 닫으면 진행 중인 조회를 취소합니다. 네이버에서 제공하지 않는 연락처 등은 빈 값으로 남습니다.

### 지도 선택과 목록 순서
- 그룹명 클릭: 해당 그룹 전체 핀에 지도를 맞춥니다.
- 장소 클릭: 핀을 중앙에 놓고 이름을 표시합니다. 핀을 한 번 클릭하면 공유 URL을 포함한 상세 정보가 열립니다.
- 그룹·장소 정렬: 저장 순서 / 이름 오름차순 / 이름 내림차순. 이름 정렬은 개인 화면에만 적용됩니다.
- 편집 모드에서 ⠿ 핸들을 마우스·터치로 드래그하거나 위/아래 방향키로 이동하면 순서가 공유 저장됩니다. 필터로 숨긴 장소의 순서는 유지됩니다. 드래그 후 정렬은 저장 순서로 전환됩니다.

- 모바일에서는 지도 위의 제목 목록을 접고 펼치며, 장소 선택 시 목록이 자동으로 접힙니다. 지도 위 ALL / ① 버튼으로 지도 범위를 바로 전환합니다. 정렬·필터는 필요할 때 펼칩니다.

- 상단 디자인 아이콘에서 Glass(기본), Bloom, Midnight 스타일을 선택합니다. 글꼴·색상·표면·버튼 스타일이 함께 바뀌며 선택은 해당 브라우저에 저장됩니다. 모바일 지도 범위 버튼은 반투명 오버레이로 표시합니다.

- 세 디자인은 PC와 모바일에 함께 적용되며 SVG 아이콘도 선형·면형·각진 선형으로 전환됩니다. 장소 편집의 핀 색상에서 직접 색을 선택하거나 카테고리 기본색으로 되돌릴 수 있고 다른 기기에도 공유됩니다. 핀은 짙은 외곽선과 그림자를 사용합니다.


### Route (방문 순서)
- 왼쪽 **그룹 / Route** 탭에서 목록을 전환합니다. Route는 그룹 소속이 없으며 서로 다른 그룹의 등록 장소를 하나의 방문 순서로 묶습니다.
- 편집 잠금을 풀고 장소 목록 또는 지도 핀의 제목·상세보기 아래에 있는 원형 **R** 또는 **+**를 누르면 Route 작성을 시작하거나 장소를 마지막 순서에 추가합니다. 같은 장소는 중복 추가되지 않습니다.
- 핀 옆과 장소 목록에 1번, 2번 순서를 표시합니다. 그룹을 바꿔도 작성 중인 선택은 유지됩니다. **−**는 작성 중인 Route에서 해당 장소만 빼고 나머지 순번을 다시 매깁니다.
- **e**를 누르면 선택 순서와 이름 입력 팝업이 열립니다. 이름을 입력하고 저장에 성공하면 공용 Route가 생성됩니다. 팝업 취소는 작성 내용을 유지하고, **x**는 작성 전체를 취소합니다. 편집 잠금을 다시 걸거나 페이지를 닫으면 저장하지 않은 작성 내용은 사라집니다.
- Route 선택 시 방문 순서대로 장소 목록과 핀을 표시합니다. Route 목록은 이름 정렬·드래그·방향키 정렬, 정보 보기·이름 수정·삭제를 지원합니다. Route 안의 장소도 이동 핸들로 방문 순서를 바꿀 수 있습니다.
- Route 삭제는 원본 장소를 지우지 않습니다. 원본 장소 또는 그룹을 삭제하면 관련 Route에서도 해당 장소가 빠지고, 모든 장소가 사라진 Route는 빈 목록으로 유지됩니다.
- 전체 백업 데이터 형식 v2에는 Route가 포함됩니다. 기존 그룹별 보고서 내보내기는 그룹 선택 후 사용합니다.
