# 가족 여행지 지도 웹앱 — 설계 문서

**작성일:** 2026-09-08  
**상태:** 승인됨

---

## 1. 프로젝트 개요

가족이 함께 방문하거나 방문 예정인 국내 관광장소를 여행 그룹 단위로 관리하는 웹앱.  
네이버지도 공유링크를 붙여넣으면 장소 정보가 자동으로 채워지고, 지도 위에 마커로 표시된다.

**핵심 제약:**
- 모든 서비스 무료 사용
- GitHub 소스 버전 관리
- 비개발자도 운영 가능한 구조

---

## 2. 계층 구조

```
앱
└── 여행 그룹 (Travel Group)  ← 상위 개념
      └── 장소 (Place)        ← 하위 개념
```

**예시:**
```
├── 🏯 2026 가을 경주 가족여행
│     ├── 불국사
│     ├── 교리김밥
│     └── 라한셀렉트경주
└── 🌊 2026 겨울 강원도 스키여행
      ├── 하이원리조트
      └── 속초 아바이마을
```

---

## 3. 기술 스택

| 역할 | 기술 | 비용 |
|------|------|------|
| 프론트엔드 | Vanilla HTML + CSS + JavaScript | 무료 |
| 호스팅 | Vercel | 무료 |
| 버전관리 | GitHub | 무료 |
| 지도 | Naver Maps JavaScript API | 무료 (NCP 클라이언트 ID 필요) |
| 데이터 저장 | localStorage | 무료 |
| 기기 간 공유 | JSON 내보내기/가져오기 | 무료 |
| 네이버 링크 파싱 | Vercel 서버리스 함수 | 무료 |

## 4. 아키텍처

```
[GitHub 저장소]
      ↓ push → 자동 배포
[Vercel]
  ├── 정적 파일 (HTML/CSS/JS)    → 웹앱 화면
  └── /api/naver-place.js       → 서버리스 프록시

                    [브라우저]
                      ├── Naver Maps JS API  → 지도 렌더링

```

## 7. 네이버 링크 자동 파싱 흐름

```
사용자 링크 붙여넣기 (naver.me/XXXXX 또는 map.naver.com/...)
        ↓
브라우저 → GET /api/naver-place?url=<링크>
        ↓
Vercel 서버리스 함수:
  1. naver.me 단축 URL → HTTP 리다이렉트 추적 → 전체 URL 획득
  2. URL에서 place ID 추출 (정규식)
  3. 네이버 내부 API 호출: /v5/api/sites/summary/{placeId}
  4. 장소명, 주소, 연락처, 좌표, 카테고리 파싱
        ↓
폼 자동 입력 → 사용자 확인/수정 → 저장
```

**실패 시:** "정보를 가져오지 못했습니다. 직접 입력해주세요" → 수동 입력 폼

## 8. 핵심 기능 목록 (CRUD)

### 여행 그룹
- 생성: 이름, 목적, 지역, 날짜, 이모지 설정
- 조회: 사이드바 목록, 클릭 시 해당 그룹 장소 표시
- 수정: 그룹 정보 편집
- 삭제: 그룹 및 하위 장소 전체 삭제 (확인 팝업)

### 장소
- 생성: 네이버 링크 붙여넣기 → 자동 파싱 → 확인/수정 → 저장
- 조회: 목록 카드 + 지도 마커 + 마커 클릭 팝업
- 수정: 장소 정보 편집 (링크, 이름, 주소, 메모, 태그 등)
- 삭제: 단일 장소 삭제

### 데이터 관리
- JSON 전체 내보내기 (모든 그룹 + 장소)
- JSON 가져오기 (기존 데이터 유지하며 새 항목 추가 병합 또는 전체 덮어쓰기 중 선택)

## 11. 배포 흐름 (비개발자용)

1. GitHub 저장소 생성
2. Vercel 계정 생성 (GitHub 로그인)
3. Vercel에서 GitHub 저장소 연결
4. NCP(네이버 클라우드 플랫폼)에서 Maps API 클라이언트 ID 발급
5. Vercel 환경변수에 클라이언트 ID 입력
6. 이후: 파일 수정 → GitHub push → 자동 배포
